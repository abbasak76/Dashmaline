مرکز هوشمند تصمیم‌گیری مالی اخوان — نسخه تخت (بدون پوشه)
============================================================

همه فایل‌ها در ریشه هستند. فقط این ۵ فایل را در مخزن GitHub آپلود کنید:

  Index.html
  meta.js
  coding.js
  bad.js
  data.js

روی GitHub:
1. مخزن Public بسازید
2. Add file → Upload files
3. این ۵ فایل را یکجا انتخاب و آپلود کنید
4. Settings → Pages → Source: main / root → Save
5. لینک: https://USERNAME.github.io/REPO-NAME/

اولین بار چند ثانیه برای لود data.js صبر کنید.
